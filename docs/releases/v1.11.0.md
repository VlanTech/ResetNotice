# ResetNotice v1.11.0

## 全账户组件修订

- 原先的斜向 StackView 已替换为纵向 ListView。每张卡片尽量占据完整桌面组件高度，依次排列且间隔 6dp，不缩小卡片给后方层留空间。非可见行不叠在当前行后；滚动时使用原生边缘渐隐。
- Android 12+ 较小账户集合保留直接数据，旧系统或大型集合使用按需适配器。组件布局只在首次安装、迁移、尺寸或适配模式变化时完整更新；普通刷新保留组件视图并使用稳定账户 ID 和可缓存的增量更新。服务端旧集合在绑定时就加载本地数据，并提供加载占位，以减少切换主屏页返回后的空白。
- 覆盖安装后打开应用一次，会尝试迁移原桌面全账户组件。无需主动删除账户或重建计时数据；桌面系统若保留旧组件缓存，可移除并重新添加该桌面组件。
- Android RemoteViews 不允许应用自定义桌面组件的触摸监听及整卡动画，因此滚动惯性和边缘淡出采用系统支持的布局效果，而非应用内可精确控制的整卡交叉淡入淡出。

## 毛玻璃

- 外观设置分别提供透明度（0–100%）与模糊度（0–100%）滑杆，增加实时材质预览。
- 模糊度为 0 时使用无模糊渐变；非零时生成主题一致的本地材质纹理并通过可调半径的扩散过滤软化边缘。透明度独立应用于底层，不会模糊文字、图标或倒计时。100% 透明时材质不可见。
- Android 桌面组件不直接控制宿主的壁纸合成，此效果为自身材质的拟毛玻璃，不读取、不捕获或实时模糊用户壁纸，不新增任何权限。
