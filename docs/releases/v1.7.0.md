# ResetNotice v1.7.0

发布日期：2026-11-26 · 版本号：8 · 开发者：Vlan_Tech

[下载签名 APK](../../releases/ResetNotice-v1.7.0.apk)

此版优先解决不依赖网络的后台提醒调度和可诊断性。尚未接入真正的国内厂商云端推送，不能以品牌识别替代应用授权。

## 新增

- 设置中可开启系统闹钟增强提醒。实际用户可见的提前或到点通知使用 `AlarmManager.setAlarmClock`，有精确闹钟权限才生效；关闭通知的静默续排仍使用普通闹钟。
- 一次性 60 秒后台送达测试：由系统定时广播触发，记录回调的实际时间、延迟、登记模式及通知是否被限制。不启用后台心跳，也不启动窗口。
- 最近一次有效额度闹钟回调时间和延迟。
- 原生厂商通道候选识别，适配 OPPO、realme、一加、vivo、iQOO、小米、Redmi、POCO、荣耀、华为和魅族；具体设备支持情况需要 SDK 实际检测与厂商授权。
- 新增[国内厂商推送调研与接入方案](../domestic-push.md)。

## 实机测试

1. 覆盖安装后打开一次，核对通知、精确闹钟与后台活动权限。
2. 设置页关闭常驻计时通知并开启系统闹钟增强提醒。
3. 点击「60 秒后台送达测试」并开始。划掉应用最近任务、锁屏，断开网络，等待约一分钟。
4. 检查是否收到测试通知，再打开软件进入设置查看实际系统回调时间。
5. 如果显示系统回调已提交通知，但未看到通知，检查通知渠道、勿扰、锁屏显示；如果始终无系统回调，检查设备后台和自启动权限。单次延迟并不能证明是系统永久拦截。

增强模式可能使系统显示下一次闹钟图标，并有额外电量开销；默认关闭，可随时关闭。系统强行停止仍具有最终控制权。
