# ResetNotice v1.2.0 · 自动循环与系统时钟同步

本版本完善了多账户额度管理，首次设置后即可按周期自动续排，不再需要每轮手动修改重置时间。

### 更新内容

- 系统秒钟同步，重置时间对齐整分钟，倒计时精确显示至秒。
- 短时限额默认每 5 小时循环，支持修改循环周期；周限额每 7 天循环。
- 跨过多个周期时自动补算下次重置时间，不因延迟提醒而积累偏差。
- 折叠视图同时显示倒计时与具体重置日期时间，设置按钮右移。
- 新增 270 ms 额度设置展开/收起动画，保留局部更新机制。
- 保留现有多平台、多账户、提前/到点通知与日夜间主题。

### 安装

下载 Release 附件 `ResetNotice-v1.2.0.apk`。兼容 Android 6.0（API 23）及以上版本，使用与此前版本一致的签名，可直接覆盖安装并保留原有账户与提醒配置。

旧版录入的时刻在升级时会对齐其对应分钟的第 00 秒。首次打开请检查通知及精确提醒权限；实际通知到达时间受 Android 后台管理限制。
