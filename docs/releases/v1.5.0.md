# ResetNotice v1.5.0 · 实时排序、交互升级及通知重构

- 动态小时限额命名（以用户配置的循环周期为准，初次剩余时长与周期相互独立）。
- 手动拖动卡片/辅助上下移动；自动按最近一次未来重置时间排序，到期续排时实时调整。手动顺序不会被自动排序覆盖。
- AI 厂商口语别名扩充，哈基米和氢基米匹配 Gemini，做题龙和鸡皮提匹配 OpenAI 等。
- Android 原生预测式返回，设置页可开关触感反馈。
- 通知标题不再重复应用名；常驻与提前提醒以剩余时间为标题，到点提醒以 AI 名称为标题。
- 复核后台保活：最近任务移除时确认闹钟，注册有效闹钟不先取消旧调度，立即显示前台服务通知、支持亮屏刷新；电池优化状态和后台运行设置集中提供。不尝试绕过 Android 的强行停止或 OEM 硬停止。

示例（简体中文）：

- 常驻：距重置还有 1小时 44分钟；ChatGPT · 主账号 · 5小时限额；重置：11-25 18:46:00；共 3 个额度计时中。
- 提前：距重置还有 15分钟；ChatGPT · 主账号 · 5小时限额；重置：11-25 18:46:00。
- 到点：ChatGPT 额度已重置；主账号 · 5小时限额；已重置：11-25 18:46:00；下次：11-25 23:46:00。
