# ResetNotice v1.3.0 · 后台持续计时

本次更新提高了清理最近任务后的提醒可靠性：保存有效计时器时启动用户可见的前台服务，并与独立的系统闹钟配合。清除所有计时器将自动退出服务。

- 计时服务在最近任务被划掉时继续运行，并请求系统在普通进程回收后恢复。
- 通知栏独立显示后台计时状态，原有的提前及到点提醒保留。
- 重启设备、升级应用或系统时间变化时恢复计时调度。
- 首页新增后台运行状态及设置入口。
- 无永久唤醒锁；Android 系统的强行停止和厂家电池限制仍有效。

安装后请先打开应用，允许通知及精确闹钟，确认「后台计时：运行中」。建议在 ColorOS 的应用详情允许后台活动和自启动，并按需锁定最近任务卡片。

签名与旧版一致，支持覆盖安装，保留已有账号及计时配置。420 项计时断言和 459 项数据、后台计时快照及调度标识断言通过；APK 签名验证通过，尚待真机验证后台行为。
