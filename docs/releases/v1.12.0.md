# ResetNotice v1.12.0

发布日期：2026-11-26 · 版本号：13 · 开发者：Vlan_Tech

[下载签名 APK](../../releases/ResetNotice-v1.12.0.apk)

## 全账户组件

通用桌面组件只渲染一个账户，取消旧的 ListView 滚动窗口、行间距及渐隐。上下箭头每次切换一个账户，到达首尾后停止，页码展示当前位置；自动重排序、定时刷新、桌面返回、组件恢复时保持当前账户 ID。删除当前账户时回到列表首项，无账户时展示添加提示。两类组件均为默认 4×3，尺寸配置一致。

## ColorOS 原生叠卡

设置 → 外观 → 系统原生叠卡 → 添加账户卡片。分别添加账户并调整至相同尺寸，在支持堆叠的桌面上长按拖动卡片重合，再上下滑动切换。ColorOS 16 用户手册描述了该操作；其更新支持第三方插件堆叠。应用只请求标准 Android 小组件添加，每次由用户确认；系统桌面管理叠卡手势、限位、动画和样式。其他桌面可使用通用翻页卡。

## 背景透明度

上一版本滤波只改变卡片自身材质，并不模糊实际壁纸，故删除该功能和滑杆。透明度仍独立于文字、计时和进度，用户原有透明度偏好保留。真正的桌面背景模糊由 Launcher 的合成器控制；Android 的[窗口背景模糊 API](https://developer.android.com/reference/android/view/Window#setBackgroundBlurRadius(int)) 用于自身窗口，不适用于由桌面宿主管理的 RemoteViews。未新增权限，未采集壁纸。

## 验证与升级

1077 条 JVM 断言通过，包含翻页限位、账户 ID 保留、重排序、删除及恢复；11 种语言、资源编译、原始发布签名校验通过。覆盖安装后打开应用一次刷新旧组件，原有账户和提醒数据保留；旧 4×4 组件由桌面调整大小，或移除后重新添加 4×3。ColorOS 实机原生叠卡及背景效果仍需在支持的设备上确认。
