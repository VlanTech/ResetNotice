## 更新

- 常驻计时通知可在设置中独立关闭，关闭前台服务不会关闭额度提醒或循环。
- 支持 Direct Boot：首次解锁前根据最近一条已开启的提醒的时间安排通用通知；首次解锁后恢复全部计时器与闹钟，无须启动活动窗口。通用通知不包含 AI、账户名称或凭据。
- 设置页新增开机恢复诊断、GMS 组件状态与对应权限提示，所有新文案适配 11 种语言。
- 继续使用独立系统闹钟；本版未接入 Firebase 云推送，不增加联网权限。

## 建议测试流程

1. 覆盖安装并打开一次，确认原有计时器保留。
2. 在系统允许通知、精确闹钟、后台活动及自启动后，创建一个近期的测试提醒，关闭常驻计时通知并划掉最近任务，检查到时提醒。
3. 开启常驻通知，重启手机。首次解锁后等待系统广播送达，不打开应用窗口，检查通知栏与提醒。之后在设置页查看上次开机恢复时间和计时器数量。
4. 关闭短时或到点提醒后，检查下一周期仍自动续排；删除所有计时器后不再显示常驻通知。

系统或厂商的强行停止操作具有最终控制权。若系统阻止开机广播或取消闹钟，需要重新打开应用并核对 ColorOS 权限。Direct Boot 的通用提醒仅为首次解锁前的补充途径，不保证每个锁定期间的周期均产生详细通知。
