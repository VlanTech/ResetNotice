# ResetNotice v1.9.0

发布日期：2026-11-26 · 版本号：10 · 开发者：Vlan_Tech

[下载签名 APK](../../releases/ResetNotice-v1.9.0.apk)

## 桌面卡片

- 已保存的账户在齿轮管理中提供「添加桌面卡片」。Android 8.0 及以上且桌面支持直接固定小组件时，会由系统提示确认；其他桌面可长按桌面，通过小组件选择器添加并选定账户。
- 每张卡片独立保存账户 ID，可多账号并行。使用主题对应的 AI 标识、账户备注、已配置额度的实时剩余时间、日期及进度线。未设置的额度不显示，删除账户后卡片可重新绑定。
- Android 7.0 及以上原生 `RemoteViews/Chronometer` 在桌面自身计时，不需要每秒启动 App；Android 6.0 静态刷新。计划编辑、周期推进、应用主题/语言变化、设备时钟校正、开机恢复和系统周期更新时重绑目标。桌面细线进度随刷新更新，文本在支持的系统上连续计时。实际跨周期刷新由系统闹钟与小组件宿主送达保障，系统强行停止仍具有最终控制权。
- 继续完全离线，无新增联网权限。

## 交互

- 主页面应用标识/标题/齿轮固定为顶部交互层，设置页固定返回箭头和标题；渐变半透明拟毛玻璃遮罩在内容滚动时形成分层。
- 原生卡片拉伸继续禁用，边缘拖拽归位耗时延长，单次惯性滑动抵达上下边界也带有轻柔的内容位移回弹。
- 折叠状态下的细线分开放在各自额度重置日期下面，只显示实际设置的额度。未设置的展开倒计时也不绘制空进度底色。

## 验证

1022 条 JVM 断言通过，包括账户小组件绑定隔离、删除、恢复、重复绑定、重置时间推进及单调计时基准换算。11 种语言资源、日夜小组件布局、组件清单和原发行签名通过构建验证。ColorOS 桌面实际固定行为、主题重绘和滑动动画未在实机上验证。
