# ResetNotice v1.8.0

发布日期：2026-11-26 · 版本号：9 · 开发者：Vlan_Tech

[下载签名 APK](../../releases/ResetNotice-v1.8.0.apk)

## 更新

- 账户管理（新增及编辑）支持设置每日免打扰时段，设置页支持全局免打扰。默认时段 23:00—08:00，默认关闭。
- 账户自己的免打扰与全局免打扰取并集，任一窗口生效时均不发送额度提醒。时段开始包含该分钟、结束不包含该分钟。开始等于结束不允许启用。
- 提前或到点事件的计划时间或实际送达时间位于免打扰期间时跳过，不积累夜间通知；每一周期仍照常续排。常驻状态通知的开关独立保留，测试按钮为用户主动触发。
- 展开状态的倒计时以主题适配的进度色为背景，随着剩余时间减少而从右往左退去；折叠账户时改为卡片底部细线进度条，短时在上、周额度在下，关闭短时额度则只剩一条。比例以对应的循环时长计算，超过一个周期的初始剩余时长显示满格。
- 顶部和底部的边缘交互改为内容整体轻柔平移及回弹，取消原生缩放拉伸。展开与收起时进度线一同进行高度/透明度过渡。
- 设置页隐藏内部诊断与未接入的厂商通道信息，升级时清理旧版尚未完成的测试提醒；首页显示保留后台的简短提示。
